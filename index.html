Model, pengambilan data & caveat

Ringkasan metadata operasional dan batasan interpretasi, termasuk INACAWO resolusi tinggi (~3 km / 1 jam).

INACAWO (~3 km / 1 jam)

Primary · regional Gelombang · angin · arus

Model regional resolusi tinggi untuk area Labuan Bajo / Selat Padar. Dipakai sebagai referensi detail di selat yang tidak tertangkap grid GFS/HYCOM — spasial + ekstraksi titik (meteogram & rose).

Metadata

Produk INACAWO regional metocean
Resolusi horizontal ≈ 3 km
Resolusi waktu 1 jam
Jendela plot 23 Des 2025 00Z – 29 Des 2025 00Z
Field spasial Arus, angin, Hsig (average wave), swell height
Field titik Hsig, Hmax, PrimSwell, WindSpeed, SurfCurrent, SST, SSS + arah
Path figure figures/spatial/inacawo/… · figures/point/inacawo/…
CSV ekstraksi figures/point/inacawo/Metocean_Analysis_combined.csv (dan per-lokasi)

Cara data diambil

Frame spasial dari paket 23-26.zip + 26-29.zip (dinormalisasi ke t_YYYYMMDDHH.png). Ekstraksi titik + meteogram/rose dari titik.zip untuk kedua koordinat kejadian. Bukan unduhan OpenDAP/AWS seperti GFS/HYCOM di repo ini.

Caveat

  • Resolusi lebih halus dari GFS/HYCOM, tetapi tetap model — verifikasi lapangan tetap diperlukan.
  • Styling frame INACAWO mengikuti pipeline plot sumber; berbeda dari chrome Monsun pada peta GFS/HYCOM.
  • Satuan meteogram INACAWO mengikuti sumber (angin knots, arus cm/s); pembanding GFS/HYCOM di halaman ini memakai m/s untuk angin/arus.
  • Bandingkan dengan HYCOM/GFS pada waktu yang sama untuk melihat sinyal selat yang hilang di grid kasar.

NOAA GFS Wave

Primary Gelombang

Model gelombang global yang digandeng GFS. Dipakai untuk tinggi gelombang signifikan (SWH), swell primer, arah gelombang, serta angin permukaan pada grid gelombang.

Metadata

Institusi / produk NOAA / NCEP — GFS Wave (global 0.25°)
Resolusi horizontal ~0.25° (~25–28 km di lintang ini)
Resolusi waktu 3 jam (siklus 00/06/12/18 + forecast hour)
Variabel yang dipakai swh, dirpw, swell, swdir, ugrdsfc, vgrdsfc
Unit plot peta SWH & swell: meter · arah: panah normalisasi

Cara data diambil

Unduhan historis dari bucket AWS Open Data noaa-gfs-bdp-pds (bukan NOMADS realtime — retensi NOMADS terlalu pendek untuk Desember 2025). File GRIB2 gelombang gfswave.tHHz.global.0p25.fXXX.grib2 diunduh per valid time, lalu di-subset ke bbox analisis di lokal (scripts/download_gfs.py).

Caveat

  • Grid 0.25° tidak mampu merepresentasikan selat sempit di Padar / Komodo; efek bayangan pulau dan channeling lokal hilang/tersamar.
  • Densifikasi ke 0.01° pada peta hanya interpolasi + smoothing tampilan — tidak menambah informasi fisik.
  • Arah gelombang memakai konvensi meteorologi “dari mana datang”, lalu dikonversi ke vektor propagasi untuk panah.
  • Perbedaan SWH model vs laporan 2–3 m bisa berasal dari resolusi, lokasi titik sampling, atau ketidakpastian laporan lapangan.

NOAA GFS Atmos (10 m wind)

Primary Angin

Komponen angin permukaan 10 m dari paket atmosfer GFS 0.25°, untuk meteogram dan peta angin.

Metadata

Institusi / produk NOAA / NCEP — GFS pgrb2 0.25°
Resolusi horizontal ~0.25°
Resolusi waktu 3 jam
Variabel u10, v10 (m/s; peta dikonversi ke knot)

Cara data diambil

Dari bucket yang sama (noaa-gfs-bdp-pds), file gfs.tHHz.pgrb2.0p25.fXXX. Sedapat mungkin memakai byte-range lewat file .idx agar hanya field u/v 10 m yang diunduh, lalu di-subset ke domain (scripts/download_gfs.py).

Caveat

  • Tidak menangkap orografi pulau kecil / sheltering lokal di rute Labuan Bajo–Padar.
  • Angin GFS Atmos dan angin permukaan GFS Wave berasal dari paket berbeda; boleh berbeda tipis pada titik yang sama.
  • Forecast hour pendek dipakai untuk membangun deret historis valid-time.

HYCOM ESPC-D-V02

Primary Arus

Arus permukaan (lapisan terdekat permukaan) dari archive HYCOM ESPC-D-V02, untuk peta dan meteogram arus.

Metadata

Institusi / produk HYCOM Consortium — ESPC-D-V02 (u3z / v3z)
Akses THREDDS OpenDAP tds.hycom.org
Resolusi horizontal ~1/12° (orde ~9 km; tergantung grid native produk)
Resolusi waktu 3 jam (disample ke step konfigurasi)
Variabel water_u, water_v, speed (m/s; peta ditampilkan cm/s)
Kedalaman Permukaan (depth ≈ 0, nearest)

Cara data diambil

Subset OpenDAP tahunan ESPC-D-V02/u3z/{year} dan ESPC-D-V02/v3z/{year} untuk rentang waktu + bbox, digabung jadi NetCDF lokal (scripts/download_hycom.py). OpenDAP dipilih karena request NCSS rentang harian untuk v3z sering stall.

Caveat

  • Arus di selat sempit / dekat pantai sensitif terhadap masking darat dan resolusi; nilai di titik pantai bisa memakai nearest wet cell.
  • Titik dugaan tenggelam vs Loh Pede bisa sangat berbeda karena topografi pantai dan posisi relatif terhadap selat — beda sinyal di meteogram bukan artefak plotting semata.
  • Produk archive ESPC; bukan observasi in-situ. Verifikasi lapangan tetap diperlukan untuk investigasi forensik.

ERA5 (opsional)

Optional Reanalisis

Reanalisis ECMWF lewat Climate Data Store — kandidat pembanding gelombang/angin 1-jam. Belum menjadi sumber primary di halaman ini.

Metadata & pengambilan

Akses CDS API (~/.cdsapirc + lisensi ERA5)
Resolusi ~0.25°, 1 jam
Skript scripts/download_era5.py (skip jika kredensial absen)

Caveat

  • Latensi/reanalisis: tidak realtime; butuh akun CDS.
  • Resolusi spasial masih kasar untuk selat sempit — mirip GFS untuk channeling lokal.

CMEMS global ocean (opsional)

Optional Arus

Analisis/prakiraan fisika laut global Copernicus Marine sebagai pembanding arus permukaan hourly.

Metadata & pengambilan

Dataset default cmems_mod_glo_phy_anfc_0.083deg_PT1H-m
Resolusi ~1/12°, 1 jam
Akses copernicusmarine login / env credentials
Skript scripts/download_cmems.py

Caveat

  • Produk model global; kualitas pantai/selat terbatas.
  • Perlu kredensial Copernicus Marine; skip otomatis jika tidak tersedia.
Catatan metodologi tampilan. Field spasial GFS/HYCOM dapat di-densifikasi ke 0.01° (~1.1 km) dengan interpolasi linear + Gaussian ringan (refine_field.py) hanya untuk keterbacaan peta — bukan resolusi fisik baru. Sampling titik memakai interpolasi, dengan fallback ke sel laut terdekat jika titik jatuh di mask darat. Frame INACAWO memakai resolusi native model (~3 km). Konfigurasi event: event.yaml.
